# .claude/ Documentation System

Start here: MASTER_PLAN.md (roadmap) -> CURRENT_PHASE.md (where we are) ->
ARCHITECTURE.md (how it fits together) -> plans/pageN.md (what's being built
right now). DECISIONS.md indexes ADRs. RESEARCH.md indexes research notes.
PROGRESS.md is updated after every meaningful implementation step — it is the
fastest way to answer "what's the state of this project."
